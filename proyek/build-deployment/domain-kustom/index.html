Tipe Nama Nilai

Untuk root domain (@): sebagian provider tidak menerima CNAME di root — gunakan fitur "CNAME Flattening" (Cloudflare) / "ALIAS" / "ANAME" dengan nilai yang sama. SSL otomatis aktif beberapa menit setelah DNS terverifikasi.
